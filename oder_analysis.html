Analysis Plan

Statistical analysis strategy for OderTogether survey data

🎤 INTERVIEW KEY - Statistical Rigor

  • Measurement invariance (Kyle et al. 2026): Before comparing German-Polish means, MUST test configural → metric → scalar invariance. Ensures items measure same construct across countries. This is THE standard for cross-cultural research.
  • Factor analysis standards: KMO ≥0.80, Bartlett's p≤0.05, factor loadings ≥0.40, Cronbach's α ≥0.70 per Kyle et al. (2026). Use EFA for exploratory work, CFA for validating established structures.
  • Content analysis (Kochalski et al. 2026): Theoretical saturation (~80-100 responses per country), hybrid deductive-inductive coding, inter-coder reliability (Cohen's Kappa ≥0.70), reflexivity documentation.
  • Creel survey weighting: Weight by encounter probability to correct avidity bias (de Kerckhove et al. 2026). Use Model II regression for temporal extrapolation (Alexiades et al. 2015).
  • Sample size adequacy: n=1,200 provides 5-10 respondents per item for factor analysis (Kyle et al. 2026 guideline). Adequate power for cross-country comparisons with medium effect sizes.
  • Reproducibility: All analyses in R/Python with version-controlled code (GitHub), open data (where permissible), and documented analytical decisions. Follows open science best practices.

This analysis plan outlines the statistical approaches for examining ecosystem services priorities, cross-border comparisons, stakeholder trust, and integration across the three survey instruments. All analyses will be conducted in R and Python with reproducible code.

1. Data Preparation & Quality Control

Quality Screening

  • Remove speeders (completion time < 5 min for resident survey, < 2 min for creel)
  • Flag straight-liners (same response to all Likert items)
  • Check attention checks and budget allocation validity
  • Examine missing data patterns (MCAR, MAR, MNAR)
Sample Code: Quality Flags
# Flag low-quality responses
df <- df %>%
  mutate(
    speeder = ifelse(completion_time < 300, 1, 0),
    straightliner = apply(select(., starts_with("es_")), 1, 
                          function(x) length(unique(x)) == 1),
    budget_valid = ifelse(budget_total == 100, 1, 0)
  ) %>%
  filter(speeder == 0 & straightliner == FALSE & budget_valid == 1)

Representativeness Check

Compare sample demographics to census data for German and Polish border regions. Compute post-stratification weights if sample deviates significantly on age, gender, or education.

2. Cross-Border Measurement Equivalence 🎤

Testing Measurement Invariance

CRITICAL (Kyle et al. 2026 psychometric standards): Before comparing German and Polish responses, verify that ES items measure the same constructs across countries. Use multi-group confirmatory factor analysis (CFA) to test invariance levels. This is THE standard for cross-cultural research—without scalar invariance, mean comparisons are not valid.

Configural Invariance (Step 1)
Same factor structure in both countries. ES items should load on similar dimensions (regulating, provisioning, cultural). Tests whether Germans and Poles conceptually group ES similarly.
Metric Invariance (Step 2)
Equal factor loadings across countries. Ensures a 1-point increase means the same thing in Germany and Poland. Required for comparing relationships (correlations, regressions).
Scalar Invariance (Step 3 - REQUIRED for mean comparisons)
Equal intercepts across countries. Required for comparing mean scores. If this fails, use partial invariance (freeing problematic items) or alignment methods. Without scalar invariance, "Germans rate biodiversity higher" is not interpretable.
# Multi-group CFA for measurement invariance
library(lavaan)

model <- '
  regulating =~ es_water_quality + es_flood + es_climate
  provisioning =~ es_fish + es_fishing
  cultural =~ es_recreation + es_beauty + es_wellbeing + es_culture
'

fit_configural <- cfa(model, data = df, group = "country")
fit_metric <- cfa(model, data = df, group = "country", 
                  group.equal = "loadings")
fit_scalar <- cfa(model, data = df, group = "country", 
                  group.equal = c("loadings", "intercepts"))

# Compare model fit (ΔCFI < 0.01, ΔRMSEA < 0.015 support invariance)
lavTestLRT(fit_configural, fit_metric, fit_scalar)
compareFit(fit_configural, fit_metric, fit_scalar)

3. Ecosystem Services Priorities

Importance Ratings Analysis

Key Research Questions:

  • Which ES are rated most/least important overall?
  • Do Germans and Poles prioritize different services?
  • How do priorities vary by distance from river, visit frequency, and activities?
  • Do anglers value different services than non-anglers?
Approach: Ordinal Regression
Likert data (1-5) is ordinal, not continuous. Use ordinal logistic regression (proportional odds model) or ordered probit to predict ES importance from country, demographics, and use patterns.
library(MASS)

# Predict water quality importance
model_water <- polr(es_water_quality ~ country + distance + 
                    visit_frequency + angler + age + education,
                    data = df, Hess = TRUE)

# Odds ratios
exp(coef(model_water))

Priority Rankings (Top 3)

Q7 asks respondents to select their top 3 priorities. Analyze selection frequencies and use multinomial logistic regression to predict which ES are chosen based on respondent characteristics.

Approach: Choice Modeling
Model the probability of selecting each ES as a function of country, user type, and demographics. Can test whether anglers disproportionately select fish-related ES.

4. Tradeoff Analysis

Budget Allocation (Q8)

Budget data are compositional (4 values summing to 100). Standard regression is inappropriate because components are not independent. Use compositional data analysis or Dirichlet regression.

Approach: Dirichlet Regression
Models proportions that sum to 1. Allows testing whether Germans allocate more to "biodiversity & habitat" while Poles allocate more to "water quality & pollution control."
library(DirichletReg)

# Prepare compositional data
budget_matrix <- DR_data(df[, c("budget_water", "budget_biodiversity", 
                                 "budget_climate", "budget_recreation")])

# Dirichlet regression
model_budget <- DirichReg(budget_matrix ~ country + distance + 
                          visit_frequency + angler,
                          data = df)

summary(model_budget)

Consistency Check

Do importance ratings (Section B) predict budget allocations (Q8)? People who rate biodiversity highly should allocate more budget to biodiversity restoration. Test with correlation or regression.

5. Trust & Governance Analysis

Trust Patterns

Key Research Questions:

  • Which stakeholder groups are most/least trusted?
  • Do trust levels differ between Germany and Poland?
  • Does trust predict ES priorities or management preferences?
  • Are there trust "profiles" (e.g., high science trust + low government trust)?
Approach 1: Descriptive Comparisons
Mean trust scores by country with t-tests or Mann-Whitney U tests. Visualize with side-by-side bar charts.
Approach 2: Trust as Predictor
Does trust in scientists predict support for biodiversity restoration? Does trust in local government predict acceptance of flood management tradeoffs? Use regression with trust scores as predictors of ES priorities or management preferences.
Approach 3: Latent Profile Analysis
Identify groups with distinct trust profiles using mixture modeling. May find "skeptics" (low trust across the board), "science believers" (high science trust), "local boosters" (high local government trust), etc.
library(tidyLPA)

# Latent profile analysis on trust variables
trust_lpa <- df %>%
  select(trust_local, trust_national, trust_scientists, 
         trust_anglers, trust_ngos, trust_industry) %>%
  estimate_profiles(3:6)

# Select best model
get_fit(trust_lpa)

6. User Type Segmentation

Identifying User Segments

Section A captures place-based connection. Use cluster analysis or latent class analysis to segment respondents into user types based on distance, frequency, and activities.

Approach: K-means or Hierarchical Clustering
Cluster on distance, visit frequency, and activity count. Expect to find: non-users, distant occasional visitors, nearby frequent users, diverse recreationists, dedicated anglers.
# Prepare clustering variables
cluster_vars <- df %>%
  mutate(
    distance_numeric = recode(distance, 
                              "<2km" = 1, "2-5km" = 3.5, 
                              "5-20km" = 12.5, ">20km" = 30),
    frequency_numeric = recode(visit_frequency,
                               "never" = 0, "1-2" = 1.5, "3-5" = 4,
                               "6-12" = 9, "monthly" = 12, "weekly" = 26),
    activity_count = rowSums(select(., starts_with("activities")))
  ) %>%
  select(distance_numeric, frequency_numeric, activity_count) %>%
  scale()

# K-means clustering
set.seed(123)
clusters <- kmeans(cluster_vars, centers = 5, nstart = 25)

df$user_type <- clusters$cluster

Comparing User Types

Once segments are identified, compare ES priorities across user types. Do frequent users value recreation more? Do anglers prioritize fish populations over aesthetics?

For anglers who completed both the resident survey and catch logs, we can test whether stated ES priorities predict actual fishing behavior.

Integration Questions:

7b. Content Analysis of Open-Ended Responses 🎤

Analyzing "Other Benefits" and Additional Comments

Following Kochalski et al. (2026) content analysis guidelines from Pope et al. (2026):

Theoretical Saturation (~80-100 responses per country)
"The researcher no longer acquires signiﬁcant new information by incorporating additional data" (Glaser & Strauss 1967). Don't need to code ALL responses qualitatively—sample until themes stabilize. For German-Polish comparison, code ~80-100 responses per country.
Hybrid Deductive-Inductive Coding
Start with deductive codes from MEA ES categories (provisioning, regulating, cultural, supporting). Add inductive codes that emerge from data. Capture both expected and unexpected ES mentions. Use sentence-level coding to preserve context.
Inter-Coder Reliability (Cohen's Kappa ≥0.70)
Train second coder, both independently code 50 responses, calculate Cohen's Kappa. If <0.70, refine codebook and resolve disagreements. Document all coding decisions in codebook for transparency and reproducibility.
Reflexivity & Positionality Documentation
"Reflexivity is the process of looking inward to identify and interrogate one's own judgements, beliefs, and practices" (Kochalski et al. 2026, p.523-524). Document: researcher biases, functional decisions during coding, positionality as American researcher analyzing German-Polish data.

6-Week Content Analysis Timeline

  • Week 1: Voyant Tools exploration for word frequency, concordance
  • Week 2: Develop hybrid codebook (deductive MEA codes + emergent themes)
  • Week 3: Train coder, test reliability on 50 responses (target Kappa ≥0.70)
  • Week 4-5: Full coding of ~160-200 responses (80-100 per country)
  • Week 6: Frequency analysis, extract representative quotes, write up results

Software: Voyant Tools (free, web-based exploration) → Atlas.ti or MaxQDA (systematic coding) → R (quantitative summary of code frequencies)

Primary tools: R (tidyverse, lavaan, MASS, DirichletReg, tidyLPA) and Python (pandas, statsmodels, scikit-learn) for analysis. All code version-controlled via GitHub with reproducible workflows using R Markdown or Jupyter notebooks.
