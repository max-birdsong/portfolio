Wolf Tolerance Predictor

Interactive ML app for exploring how demographic and wildlife value orientations relate to tolerance toward wolves.

What it does

The app predicts a binary outcome — Tolerant vs Not tolerant — using a compact feature set designed for practical deployment. Users adjust inputs and see predicted class and probability, which supports outreach planning and scenario exploration.

~70%
Accuracy (holdout)
F1 focus
Balanced classes via ADASYN
Fast
Realtime inference in Streamlit

Inputs and outputs

Model inputs

  • Age (continuous)
  • Gender (categorical)
  • Stakeholder group (GenPop, Land, Wolf, Deer)
  • Mutualism value orientation (numeric scale)
  • Utilitarian value orientation (numeric scale)

Inputs align to notebook features: Q36 (age), Q37 (gender), group, MUT_WVO, UT_WVO.

Outputs

  • Predicted class: Tolerant or Not tolerant
  • Class probability

Designed to be interpretable for policy and outreach audiences.

Model card

Algorithm

Logistic Regression with standardized numeric features and one-hot encoded categorical features.

Imbalance handling

Compared class weights, SMOTE, ADASYN, and random oversampling. Selected ADASYN with logistic regression based on cross-validated F1 macro and holdout performance, with attention to minority class detection.

Training summary

  • Pipeline: ColumnTransformer (StandardScaler + OneHotEncoder) → ADASYN → LogisticRegression
  • CV: Stratified K-fold with grid search over regularization
  • Holdout metrics: about 70 percent accuracy, balanced F1 emphasis

Known limitations

  • Compact feature set trades some raw accuracy for deployability
  • Linear decision boundary, no interactions modeled
  • Precision on Not tolerant class is moderate; threshold tuning may be useful for certain use cases
